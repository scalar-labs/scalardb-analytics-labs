# 販売ドメイン用語集

販売部門が業務で使う用語の定義です。EC（オンラインショップ）と実店舗の両方を扱います。

## 売上

- **EC売上**: EC の注文の税抜金額の合計。キャンセルされた注文と返品された注文は含めない。
  どの期間の売上かは注文日で判定する。単に「売上」と言うときは EC売上を指す。
- **店舗売上**: 実店舗の POS で記録した販売の税抜金額の合計。会員カードを使わない販売も含む。
  どの期間の売上かは販売日で判定する。
- 金額はすべて円（JPY）。税額は別の項目で管理し、売上には含めない。

## 注文ステータス

EC の注文ステータスは次のコードで記録する。

| コード | 意味 |
| --- | --- |
| shipped | 出荷済み |
| delivered | 配達済み |
| cancelled | キャンセル（売上に含めない） |
| returned | 返品（売上に含めない） |

## 会員

- **会員ランク**: 店舗会員のランク。G はゴールド、S はシルバー、B はブロンズ。
- **顧客の同一性**: EC の顧客と店舗の会員は、登録メールアドレスが一致すれば同一人物とみなす。
  店舗会員のメールアドレスは店頭で手入力されるため、大文字と小文字を区別せずに比較する。
- **両方で購入した顧客**: 同じ期間に EC での注文と店舗での購入の両方がある顧客。
